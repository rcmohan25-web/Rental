# Branding

- App name **Rental** (launcher label, splash, store listing, admin panel title **Rental Admin**).
- Owned and operated by the company **Sapati** (sapati.com). Android package id `com.sapati.rental`.
- Support and notification emails use a sapati.com address (for example support@sapati.com).

| Token | Value |
| --- | --- |
| Primary (navy) | `#0F1B3D`, white text on it |
| Button (hot pink) | `#FF3D8B`, white **bold** label, 16 sp or larger |
| Background | `#F7F8FC` |
| Surface | `#FFFFFF` |

White on pink is only about 3.3:1, so never use small text on pink. Status chips are always colour + icon + text.
Light theme first. All values live in `packages/rental_core/lib/theme/`.
