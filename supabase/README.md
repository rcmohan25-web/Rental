# supabase/

**Owner: Srijan (single writer for everything in this folder).**

`config.toml` is generated by `supabase init` (see `docs/setup/supabase-setup-srijan.md`). After running it, set
`sql_paths = ["./seed/seed.sql"]` under `[db.seed]`.

```
supabase/
  config.toml               generated by `supabase init`
  migrations/               YYYYMMDDHHMMSS_area_description.sql, never edited after merge
  functions/delete-user/    Edge Function (Deno): deletes the auth user on account deletion
  seed/
    seed.sql                LOCAL ONLY: fake users with a known password, items, bookings
    demo_seed.sql           CLOUD: no passwords; attaches fake data to users made in the dashboard
  tests/                    pgTAP: schema, RLS, storage (state machine, money, settlement come later)
```

```powershell
supabase start
supabase db reset     # migrations + seed/seed.sql
supabase test db      # pgTAP
```
